# Разработка JSONic

Нужны macOS 13+ и Xcode Command Line Tools со Swift 5.9 или новее.

```sh
./build.sh
open dist/JSONic.app
```

`./build.sh --check` собирает приложение и запускает проверки на синтетических данных. `swift run JSONicChecks` запускает их отдельно. Большой нагрузочный тест выключен по умолчанию; для него задайте `JSONIC_BENCH=1`. Фильтр проверок — `JSONIC_CHECK_FILTER`.

## Структура

- `Sources/JSONic` — интерфейс и управление фоновыми задачами.
- `Sources/JSONicCore` — CSV, импорт Excel, SQLite-индекс, поиск, экспорт и маскирование.
- `Vendor` / `ThirdParty` — исходники зависимостей и их лицензии.
- `Checks` — проверки и небольшие искусственные Excel-файлы.
- `Examples/demo.csv` — искусственный пример для демонстрации.
- `Scripts` — сборка релиза и оформление установщика.

## Данные и ограничения

CSV читается потоком, поиск использует SQLite FTS5. Индекс содержит текст исходного файла и хранится локально в `~/Library/Caches/CSVScope`. Удаление через меню «Удалить кеш файла» закрывает текущий файл и удаляет его индекс. Кеш не зашифрован.

Bundle ID `local.csvscope.viewer` и имя папки кеша сохранены для совместимости с ранее установленными локальными сборками. Переименовывать их без отдельного плана обновления не следует.

Правки и анализ маскирования используют временные SQLite-файлы. Исходный файл не изменяется; правки нужно экспортировать до закрытия. Временные данные удаляются при нормальном освобождении сессии; после аварийного завершения они могут остаться во временной папке macOS.

Экспорт сохраняется через временный файл с атомарной заменой назначения. По умолчанию перед CSV-значениями, похожими на формулы, добавляется апостроф. Это меняет значение в CSV; для точного обмена данными есть переключатель в окне экспорта. JSON/TXT эта настройка не затрагивает. Повторное сохранение CSV другим табличным редактором может изменить его обработку.

Excel: первая непустая строка — заголовок, формулы читаются по сохранённым результатам; макросы не исполняются. Оформление книги не экспортируется, защищённые паролем книги не поддерживаются. XLSX имеет лимиты распаковки и запрет внешних XML-сущностей; XLS может потребовать много памяти. Очень большие ячейки также требуют соответствующего объёма памяти.

Маскирование основано на правилах и контексте, без сетевых сервисов и загрузки моделей. Предпросмотр требует ручной проверки.

## Релиз

1. Обновите `CFBundleShortVersionString` и увеличьте `CFBundleVersion` в `Info.plist`.
2. Выполните `./build.sh --check`, затем `zsh Scripts/package-release.sh`.
3. Заберите DMG, ZIP и `SHA256SUMS.txt` из `releases/JSONic-<версия>-installer/`.
4. Закоммитьте исходники в `dev`, синхронизируйте `main` с проверенной версией и отправьте изменения на GitHub.
5. В GitHub откройте **Releases → Draft a new release**. Создайте тег `v<версия>` на соответствующем коммите `main`, добавьте описание и три файла из шага 3, опубликуйте.

Сборка универсальная: arm64 + x86_64. Пакет содержит только приложение, лицензии и инструкцию, без пользовательских данных. Скрипт отказывается перезаписывать существующую папку релиза.

Сборка подписана ad-hoc, без Developer ID и нотарификации. Для оформления DMG скрипт устанавливает `ds-store==1.3.1` и `mac-alias==2.2.2` локально в `.build/dmg-tools`; при первом запуске нужен интернет. Эти Python-пакеты не входят в приложение.
