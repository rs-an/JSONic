первый публичный релиз JSONic для macOS 13+ (Apple Silicon и Intel).

- просмотр CSV, TSV, XLS и XLSX;
- поиск по таблице и JSON внутри ячеек;
- редактирование с сохранением в отдельную копию;
- экспорт выделения и маскирование данных с предпросмотром.

для установки скачайте DMG и перенесите JSONic в «Программы». ZIP — альтернативный архив с приложением. SHA256SUMS.txt содержит контрольные суммы.

если macOS блокирует запуск: системные настройки → конфиденциальность и безопасность → «всё равно открыть». приложение пока не нотарифицировано Apple.

исходный код JSONic распространяется по лицензии MIT; сторонние компоненты — по своим лицензиям.
